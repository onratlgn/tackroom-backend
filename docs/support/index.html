TackRoom support

Help for the TackRoom app for iPhone, iPad and Android.

Contact

To report a bug, ask a question or request a feature, open an issue on GitHub. Please include your device model, OS version and the app version (Settings in the app). Don't include pairing codes, chat contents or other private data.

Getting started

  1. Install the TackRoom extension in Visual Studio Code on your computer.
  2. Run TackRoom: Pair Phone from the Command Palette. A QR code appears.
  3. Open TackRoom on your phone and scan the code.

No computer handy? Tap Try the demo on the first screen to look around with sample chats.

Common questions

The phone can't connect to my computer. Make sure VS Code is open with the TackRoom extension running. On the same Wi-Fi the phone connects directly; elsewhere it goes through a Microsoft Dev Tunnel relay that the extension sets up. If the pairing code expired, run TackRoom: Pair Phone again.

I don't get notifications. Allow notifications for TackRoom in your phone's settings, and check that the computer is still paired.

How do I remove a phone or computer? In the app, tap Remove computer. On the computer, run TackRoom: Paired Phones in VS Code and revoke the phone.

Can I turn off crash reports and usage counts? Yes: Settings > Share diagnostics.

Is my code sent to your servers? No. Your chats, files and projects only travel, encrypted, between your phone and your own computer. See the privacy policy.
