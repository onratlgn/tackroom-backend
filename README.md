# tackroom-backend

Server-side pieces for the TackRoom mobile app.

## Website (`docs/`)

Static pages served by GitHub Pages from `main` / `docs`:

- `/` — landing page
- `/privacy/` — privacy policy (App Store Connect *Privacy Policy URL*; source of truth is `tackroom-mobile/docs/PRIVACY.md`, keep them in sync)
- `/support/` — support page (App Store Connect *Support URL*)

Live at https://onratlgn.github.io/tackroom-backend/
